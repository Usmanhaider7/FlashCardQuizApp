# Flashcard Quiz App (Flutter)

A simple, clean flashcard app for studying — built with **Flutter + Hive + Provider**.

## Features
- Each flashcard shows a **question** on the front with a **"Show Answer"** button to reveal the answer
- **Next / Previous** buttons to move through the deck, with a progress bar and counter (e.g. "3 / 10")
- **Add, edit, and delete** flashcards (from the Study screen or the dedicated "My Cards" list)
- Optional **category** tag per card (e.g. "Biology", "Math") for light organization
- Comes with 3 sample cards pre-loaded on first launch so it's not empty
- **Local storage with Hive** — works fully offline, no backend needed
- Clean, minimal light UI with a single accent color

## How to Run

1. Make sure you have the Flutter SDK installed: https://docs.flutter.dev/get-started/install
2. Copy this `flashcard_quiz` folder to your machine.
3. **Important**: this folder only contains the `lib/` and `pubspec.yaml` — the
   platform folders (android/ios/etc.) aren't included. Generate them with:
   ```bash
   cd flashcard_quiz
   flutter create .
   ```
4. Then install dependencies and run:
   ```bash
   flutter pub get
   flutter run
   ```

## Notes on the Hive Model
Just like the model in `activity_model.dart` from the Fitness Tracker project,
`FlashcardModel`'s `TypeAdapter` is **hand-written** in `lib/models/flashcard_model.dart`
instead of generated by `build_runner`, so the app runs immediately with no
code-generation step. If you add new fields later, update the adapter's
`read`/`write` methods manually, or switch to `@HiveType`/`@HiveField` codegen.
